# 从安装到第一本书（使用手册）

> 目标：不读源码也能在 10 分钟内跑通「配置模型 → 建书 → 写作 → 归档 → 备份」。
>
> **[English](getting-started.en.md) · 简体中文**

## 1. 安装

1. 打开 [Releases](https://github.com/JeffGuo7/novel_studio/releases)，下载最新的
   `Novel Studio-Setup-<版本>-x64.exe`；
2. 运行安装包（当前**未做代码签名**，SmartScreen 提示「未知发布者」属正常；可在发布页核对
   `SHA256SUMS.txt`）；
3. 启动后首次打开是空书架。

> 便携版 `Portable` 不需要安装，双击即可；数据默认在「文档 / NovelStudio」。

## 2. 配置模型（必须）

点右上角「本机配置」：

1. 选择供应商（DeepSeek / OpenCode / OpenAI / Anthropic / 自定义 OpenAI 兼容端点）；
2. 选模型（默认建议 `deepseek-flash`，便宜够用）；
3. 填 API Key，保存。Key 用系统 safeStorage 加密保存在本机，不会进书库、不会进 Git；
4. 点 **「测试连接」**：会发一个最小请求，区分鉴权失败 / 网络不通 / 模型不可用；
5. 需要代理才能访问模型时，在同一页填写 **网络代理**（如 `http://127.0.0.1:7890`），保存后对模型请求和更新检查生效。

预算建议保持默认：会话 $0.50 / 单章 $0.20，到 80% 会预警，超限硬停。

> 用 **OpenCode Go** 这类套餐内计费时，助手面板显示「套餐内 · 已用 N 轮」，
> 美元金额仅作标价估算、不会触发硬停；切回按量计费的 provider 后预算恢复生效。

## 3. 新建书 / 导入已有书

- **新建**：在书架输入书名 → 「新建书」；
- **搜索/排序**：书架顶部可按书名/作者/简介搜索，按最近打开/最新创建/书名排序；
- **书籍信息**：卡片右上角铅笔可改书名/作者/简介、上传封面（改书名不会移动目录）；
- **导入**：
  - 顶栏「导入」→ 粘贴文本 / 选择本地 txt、md 文件（支持多选）；
  - 也可用番茄书源（需要本地番茄下载器，应用会提示）；
- 导入会按「第 X 章」识别章节，生成每章 Markdown + 一次 Git 提交。

## 4. 写第一章

> 编辑中每 2.5 秒无输入会自动存档到 `.studio/autosave`；如果应用崩溃/断电，重开后顶部会提示
> 「发现未保存的自动存档」，点「恢复」找回，保存成功后自动清除。

有两种方式，可以混用：

**自己写**：打开章节 →「编辑」→ 写 → 保存（Ctrl/Cmd + S）。每次保存都是 Git 提交。

**让 Agent 写**：
1. 打开要写的章节（或点「新建章节」）；
2. 右侧切到「助手」，说「续写这一章，2000 字左右」；
3. Agent 会先 `read_context` 读世界观/大纲/上一章，再调用 `search_story` 回忆旧情节，
   最后用 `write_draft` 写进**草稿**；
4. 你切到「草稿」标签看版本，满意后点「归档为第 X 章」——归档永远由你点击。

> Agent 没有归档、删除权限；它也不能直接改知识文件，只能提建议（下一步）。

## 5. 初始化知识库（推荐）

有 3 章以上之后，点顶栏「初始化知识」：

- 会分块蒸馏出：剧情总纲、世界模型、状态卡、逐章大纲、文风指南/指纹，
  以及人物卡、地点卡、势力卡、卷摘要；
- 首次全量、之后增量；已归档章节被改写/删除时会提示「重建知识」；
- **重建不会直接覆盖已有知识文件**：会生成一组 AI 建议，进入顶栏「AI 建议」逐条看 diff，接受后才写入并提交；不满意可以拒绝，旧知识保持不变；
- 成本几美分到几十美分，取决于书长；可随时关闭进度弹窗（后台继续，取消按钮可停）。

## 6. AI 建议与大纲向导

- **AI 建议**：Agent 想改大纲/设定时会调用 `propose_knowledge`，顶部出现「AI 建议 (N)」；
  点开逐条看 diff，「接受并提交」才写入正史（并产生 Git 提交），「拒绝」直接丢弃；
- **大纲向导**：顶栏「大纲向导」→ 一句创意 + 卷数 → 生成主线/分卷/世界模型建议 →
  同样走 diff 审阅。

## 7. 版本、历史与回滚

- 「历史」标签：所有提交，点开看 diff；
- 章节操作：章节标题右侧「···」菜单可插入（上方/下方）、上移/下移、合并到下一章、从光标处拆分、重新编号；
- 全书搜索：`Ctrl/Cmd + F` 搜章节和知识文件，点击结果定位；支持区分大小写、按文件/全书替换（生成一次 `[替换]` 提交）；
- 写作统计：顶栏「统计」可看今日新增、总字数、连续写作天数，并设置每日目标；统计只算正文章节；
- 回滚：历史 diff 里点「回滚到此版本」；
- 章节正文、知识文件、book.json 都在 Git 里；草稿不在 Git（独立版本目录）。

## 8. 上下文与预算

- 助手底部显示 `上下文 x / y`：按所选模型的 `contextWindow` 自动裁剪；
- 长对话可点「压缩」(`/compact`)：把早期轮次压成摘要，原文仍保留在会话文件；
- 如果请求仍然超出模型上下文，应用会**自动折叠早期消息、临时缩小输入预算并重试一次**（顶部会提示「自动压缩后恢复」）；仍失败才需要手动压缩或换更大上下文的模型；
- 会话/单章预算到阈值会提示，超限会锁输入，重启不会绕过（要改预算去配置页）。

## 9. 备份、恢复与更新

- **备份**：配置 → 数据安全 →「手动备份」，生成含每本书 `.git` 历史的 zip；
- **自动备份**：默认开启，每 3 天自动备份到「配置目录/backups」，只保留最近 5 份；可改成每天/每周、3/5/10 份，手动备份不会被清理；
- **恢复**：点「从备份恢复」选 zip → 列出备份里的书 → 勾选要恢复的书（当前已有同名书会标记跳过）；不会覆盖现有数据；恢复后自动刷新书架；
- **更新**：配置 → 更新 →「检查更新」；下载后校验 SHA256，你点「重启并安装」才会安装；
- **排障**：配置 →「打开日志目录」，日志是 JSONL，按天滚动，只存本地。

## 10. 导出书稿

顶栏 **「导出」**（有正式章节后可用）：

- **EPUB**：标准电子书格式，带目录，适合阅读器 / 自出版；
- **Markdown**：合并成单个 .md，适合备份、二次编辑、导入其它工具；
- **TXT**：纯文本，适合网文平台或直接分享。

选择格式 → 「选择位置并导出」→ 完成后可点「打开所在文件夹」。导出**只包含正式章节，不含草稿**，
也不会修改书稿或 Git 历史。

## 11. 一致性检查（只读审稿）

章多了以后，设定/时间线/人物状态容易前后打架。顶栏 **「一致性」**：

1. 选检查范围（留空 = 全书；单次最多检查最近 120 章），可填「重点关注」；
2. 开始检查：模型会对照知识库设定逐批检查，找出人物、时间线、设定、剧情四类矛盾；
3. 结果按高/中/低分级，每条带依据（第几章/哪张卡）和核对建议；
4. **只读**：不会修改书稿、知识文件或 Git 历史；报告自动存到书的 `.studio/reviews/` 目录，可按需删除。

> 成本取决于章节数：几万字通常几美分以内；范围越小越省。

## 12. 常见问题

| 现象 | 处理 |
|---|---|
| 发送消息没反应 / 报模型错误 | 配置页点「测试连接」按提示排查（鉴权 / 网络 / 模型）；OpenCode Go 选 `opencode-go`；需要代理时填写网络代理 |
| 预算超限被锁 | 配置页调高会话/单章预算，或点助手「重置」开新会话 |
| 上下文太满 | 点「压缩」；或用更强上下文窗口的模型 |
| 更新检查失败 | 网络无法访问 GitHub API 时，直接去发布页手动下载 |
| 书打不开、提示 JSON 损坏 | 从备份恢复；或在书库目录检查 `book.json`（日志会记录具体错误） |
| 想换电脑 | 备份 zip 拷过去 → 新机器安装 → 恢复备份 |
